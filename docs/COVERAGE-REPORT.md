## Наиболее приоритетные пробелы

1. **Конфиденциальность групп:** ESN-141 и публикация подписчика закрытой группы ESN-146 закрыты полностью; остаются ESN-145, ESN-147 и ESN-149 для скрытых групп. Создание hidden-группы через API сейчас возвращает 500.
2. **Почтовые уведомления:** ESN-449–458 требуют управляемого почтового ящика либо безопасного API/почтового перехватчика; UI-действия без проверки письма не закрывают кейс.
3. **Администрирование групп:** приглашение и удаление участника, а также цепочка Пользователь → Автор → Администратор → Пользователь автоматизированы; остаются полный состав меню и ожидаемый тост после смены роли.
4. **Негативные медиа:** тесты реального файла 101 МБ подготовлены, но dev не показывает ожидаемую ошибку; некорректные форматы пока проверяются только через accept-фильтры.
5. **Опросы:** два аккаунта и ветвящийся сценарий покрыты отдельно; остаются анонимная статистика, срок завершения, конкурентный выбор и отсутствующий итоговый баннер.
6. **Форматирование длинных публикаций:** ESN-223/224 покрыты в ленте; остаются медиавложения ESN-367, форматирование ESN-424 и отдельное уточнение поведения preview по ESN-423.
7. **Профили, поиск и группы:** многие кейсы имеют частичное покрытие из-за больших матриц фильтров, вариантов перехода и комбинаций видимости; их следует расширять наборами параметров.
8. **Визуальные проверки:** точечные скриншоты нужны для редактора, карточек медиа и адаптивных состояний после стабилизации UI; они не должны заменять функциональные assertions.

## Что не входит в цифру 279

В проекте есть полезные новые проверки без прямого аналога в импорте: вкладки «Скрытые»/«Удалённые», скрытие своей публикации, API-контракты, login/logout, 404 и ограничение изображения группы 16 МБ.
