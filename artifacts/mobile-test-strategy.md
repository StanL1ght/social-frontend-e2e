# Отдельный мобильный прогон

Цель — проверять адаптивную вёрстку и критичные действия на телефоне, не дублируя все desktop-сценарии. Playwright `devices` задаёт не только размер экрана, но и touch, user-agent и особенности мобильного viewport. Поэтому простой запуск desktop-тестов на ширине 390 px не равен мобильному прогону.

## Набор на каждый релиз

- Pixel 7 (Chromium/Android) и iPhone 13 (WebKit/iOS): лента, группы, каталог, профиль и «Мои публикации» без горизонтального переполнения на ширинах 320–480 px.
- Навигация и сохранение контента при изменении ширины экрана; видимость важных элементов и работа кнопки «Написать».
- Открытие редактора и мобильного меню «Действия»; доступность публикации, черновика и предпросмотра.
- Переключение вкладок «Скрытые» и «Удалённые» и отсутствие горизонтальной прокрутки.
- Переключение вкладок групп и ввод в мобильный поиск касанием.

Команда: `npm run test:mobile`. Только один движок: `npm run test:mobile:chromium` или `npm run test:mobile:webkit`.

## Расширенный прогон перед крупным изменением интерфейса

Выборочно добавить на обоих движках: создание/редактирование публикации, комментарий, реакцию, поиск, подписку/заявку в группу, карточку группы, вложения и опрос. Данные готовить через API и удалять после проверки. Чисто серверные матрицы ролей и почтовые сценарии повторять на каждом телефоне не требуется: они не зависят от адаптивной вёрстки.

Существующий ESN-36 меняет ширину внутри мобильной эмуляции, включая 1366 px. Это полезный тест перестройки интерфейса, но он не заменяет отдельный desktop-проект. Визуальные снимки следует добавлять только для стабильных ключевых экранов с закреплёнными данными и окружением; иначе сравнение будет шумным.

Основание: [Playwright emulation](https://playwright.dev/docs/emulation), [Playwright projects](https://playwright.dev/docs/test-projects), [Playwright annotations and tags](https://playwright.dev/docs/test-annotations).
